我第一次坐在双子塔下喝 teh tarik 是 2019 年的雨夜，那时还没想到自己会在 KL 长住。后来出差去过仙本那，凌晨四点的水屋外灯火零星，远处巴瑶人的小船像剪影；又在槟城打铜仔街拐进一条没招牌的咖啡馆，老板递我一杯白咖啡说"你不像游客"——那一刻我才觉得，自己开始懂这个国家。

这本册子是给所有像我一样在马来安顿下来、又有点贪心想走遍它的人。84 个景点，按从 KL 出发的方向 + 距离排序；每个我都亲自踩过，每条提示都是踩坑后的实话。

Honest Tips

博 主 的 诚 实 建 议

那些攻略不会写但你应该知道的事

✓ 应 该 做

  • 下载 Grab，城市里它就是你的私家司机。
  • 带英标三孔转换器，全马通用。
  • 清真寺 / 印度神庙前自觉脱鞋 + 借纱笼。
  • 学几句"Terima Kasih"(谢谢)，本地人会笑得灿烂。
  • 路边摊吃饭看人多的去，本地人坐才是好店。
  • 带雨伞 + 防蚊液，热带午后必下雨。
  • 跨州长途选 ETS 火车，比大巴稳。
  • 买本地电话卡 (Hotlink/Digi 10 天 30GB 仅 RM 30)。

✗ 别 这 样

  • 不要在斋戒月白天在公共场合大吃大喝。
  • 不要触摸他人头部，对穆斯林是大忌。
  • 不要用左手递物 / 接物，伊斯兰文化里左手不洁。
  • 不要在哥打巴鲁 / 哥府等保守州穿暴露。
  • 不要在路边随便换钱，去 Mid Valley / KLCC 正规店。
  • 不要相信路边主动搭讪的"导游"，多半是黑车。
  • 不要直接喝自来水，去便利店买瓶装水。
  • 不要忘了带纸巾 + 零钱，公厕没纸要 RM 0.5。

💡 钱 包 心 得

  • 大商场 / 连锁店都刷卡 / TNG E-Wallet。
  • 夜市 / 老咖啡店 / 路边摊只收现金。
  • 机场 ATM 取现汇率比换钱处稍差但安全。
  • 大额 (>RM 500) 务必护照 + 信用卡分开放。
  • Grab 餐厅推荐通常有 10-20% 折扣。
  • 跨州航班用 AirAsia / Batik / MAS，提前 2 月订便宜一半。

  • "限定优惠"按摩 / 玉器店 → 拉抬价
